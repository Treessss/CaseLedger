# Noto Sans SC for PDF export

`NotoSansSC-Regular.ttf` is a static weight-400 instance of Google's
[`NotoSansSC[wght].ttf`](https://github.com/google/fonts/blob/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf).
It is bundled so purchase PDFs embed readable Chinese text on every server and PDF viewer.
