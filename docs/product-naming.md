# 商品改名与中文映射

`product_namings` 以 `(shop_id, shopify_product_id)` 唯一定位商品，保存当前英文标题、历史标题别名、
商品中文名与颜色中文名。Shopify 商品同步及商品更新 webhook 只更新当前标题与别名，不覆盖人工中文。
订单行是下单时的快照，订单同步不得将旧标题重新写回已有商品缓存。

旧 `product_translations` 记录完整保留。首次建立身份记录时，仅从明确属于该商品 ID 的旧标题承接中文；
同名不同 ID 不自动共享映射。以后以身份记录为准，清空中文是有效操作，不能再从旧表恢复。
无法识别固定 ID 的历史自定义商品继续使用旧标题映射。

商品管理按固定 ID 汇总展示当前名称，不删除历史变体。分页和筛选只查询必要的身份与标题字段，
图片与变体聚合限制在当前页商品 ID 范围内。保存时优先使用固定 ID，允许编辑期间英文标题已变更。
订单、采购快照、库存键和库存流水原文不修改；展示层投影使用身份/别名解析中文。

上线先备份数据库并执行 Alembic `3c7c7690f253`，再通过 `reconcile_names` 承接历史映射。
已有混合标题时可先调用现有 Shopify 只读目录接口核实当前名称。后台同步不持有仓储使用的店铺锁；
新映射编辑只锁对应命名记录。旧的无 ID 映射仍保留原有店铺锁保护。
