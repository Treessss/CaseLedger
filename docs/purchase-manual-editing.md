# 采购单手动添加商品与修改数量

- 采购管理可“手动创建采购单”，从当前店铺商品大类、颜色／配置、完整型号中选择；无需绑定订单。
- 草稿、采购中、分批到货清单支持“添加商品 / 编辑数量”；结束到货或撤销后的清单不能改历史，应另建清单。
- 原商品修改的是本单总采购量。增量与手动新增均为额外备货，不虚增原订单／售后单需求。
- 减量优先移除未清点额外备货，然后移除未清点关联需求；减少的在途供应立即释放，仍缺货的订单重新进入待采购。
- 已清点合格、货损、确认缺货之和为编辑下限。修改不会改历史批次、实物库存、订单内容、面单或出库状态；未清点商品设为 0 可移除，但清单不能完全为空。
- 保存后采购件数、分组、PDF/Excel 导出和待采购计算均使用新数量。
- 每次编辑要求原详情的 edit_token；他人编辑、入库、确认采购或撤销后令牌失效，返回 409，防止并发覆盖及重复添加。
- 编辑前后快照、操作人及 UTC 时间记录在 purchase_list_edits；新表通过 Alembic 迁移 9c4f70981469 创建，不改写已有业务数据。
- 新接口均置于 /api/purchase-lists 前缀，要求 fulfillment 权限并检查店铺权限，商品选择不要求额外的售后／库存／商品维护权限。

测试包含普通采购、独立备货、部分收货、缺货补采衔接、权限隔离、导出、200 个以上变体完整分页，以及独立 PostgreSQL 的空库迁移与双人编辑冲突检查。
