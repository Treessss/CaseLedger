# 后台邮件草稿任务

- 点击才创建任务，不自动发现邮件、不发送邮件、不创建 Shopify 折扣。
- 每个店铺最多一批活动任务。刷新、切换页面、关闭浏览器不会终止后台任务。
- 数据库保存候选编号、逐封结果和进度；旧来信、忽略邮件及已有草稿自动跳过。
- 同一封最多尝试三次；失败原因展示在页面。凭证/余额问题暂停整批。
- 停止会保留结果，当前正在生成的一封可能完成；可以单独重试失败和未完成项。
- 每分钟恢复检查仅重投超过 11 分钟没有心跳的已请求任务，不生成新任务。
- 服务器独立 `mail-worker` 消费 `mail` 队列，避免长任务占用订单同步进程。
- 本地 `python start_celery_worker.py` 已包括 `mail` 队列，修改后需重启本地 worker。
- 模型迁移：`72bc3fe916d0`，必须先备份并运行 `flask db upgrade`。
- 草稿指纹 v2 排除订单技术更新时间，保留商品、备注、地址、物流和仓库状态变更校验。
- 旧指纹仍按旧规则校验，不将旧草稿误判为新指纹。重新生成后采用 v2。
- AI 输出因长度截断时自动增加长度重试一次；429/服务端暂时异常由后台任务重试。
