# 连续扫码出库

- 物理面单（4PX、GV、OLS、长数字等）直接请求出库接口；不再先查询整张装箱单。
- 出库接口仍执行原有事务、库存、打包占用、实体条码及防重复校验，不修改出库规则。
- 订单号和 CF 售后编号仍仅查询，不会因为输入参考编号而出库。
- 接口确认成功后才发出成功声音；不提前显示虚假的成功结果。
- 页面商品查询和今日流水异步刷新，不再锁住扫码输入。
- 连续扫码按顺序提交；当前处理和排队的相同面单去重，排队最多 20 张。
- 队列满或出库失败显示具体条码与原因，不能静默丢弃；失败后继续处理后面的面单。
- 扫码枪没有回车/Tab 的条码，静止 120 毫秒后提交；手动输入仍保留 350 毫秒。
- 队列是当前页面的临时队列，请等全部确认后离开页面。处理期间刷新会提示离开风险。
- 网络异常只代表未确认成功，必须核对流水；不自动重试出库写入，避免重复操作。
- 已经出库的包裹再扫一次不会重复出库，但仍会补查清单并展示商品图片和收货信息，方便对照实物核对（重复扫码不写异常记录）。
- 结果区与装箱核对一致：左边商品图片，右边「收货信息核对」；部分包裹已扫时提示还剩几个包裹，不把整单误报成已出库。
