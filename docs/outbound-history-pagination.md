# 出库历史分页与撤回

`GET /api/shipping/outbound/recent` 支持 `shop_id`、`page`、`per_page`、`search`。
每页默认 20 条，上限 100 条；兼容旧 `limit` 参数作为每页条数。**总历史无条数或日期截断**。

- 在数据库中按原订单与售后单分别选取最新一次扫码记录，再搜索、排序、分页。
- 撤回状态核对该目标的全部后续撤回事件，不再只取最近 500 次。
- 返回 `pagination: {page, per_page, total, pages}`，超出最后一页时回落到最后一页。
- 搜索记录中的订单号（含 CF）或扫码面单号；重复扫码不制造多行。
- 页面分页按店铺保存，搜索回到第一页；旧查询响应不能覆盖新查询。
- 只查询本页的订单标题与状态，不加载商品、库存与采购详情。
- 撤回沿用已有事务、权限和库存回退逻辑，没有放宽重复撤回或历史未扫码状态校验。
- 只列已有扫码出库事件；仅 Shopify 已发货或其他未扫码的历史标记不会凭空生成撤回记录。

无模型或数据库结构变更。测试包含 126 个目标分页、85 次重复扫描、501 次后续撤回、
原订单与 CF 分开统计，以及第 50 条后记录可查找并实际撤回（隔离测试库）。
