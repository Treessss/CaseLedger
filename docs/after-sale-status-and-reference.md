# 售后采购状态与有效编号

- 售后列表、详情分别展示采购进度和实物库存情况。现货可满足本单不代表已经采购到货，也不代表整店订单都够；扫描仍按实时公共库存校验。
- 接口保留兼容的 `status`，新增 `procurement_status`、`stock_status`、`stock_missing_quantity`。采购进度只依据关联采购清单，不从库存反推；这些新增字段不增加列表查询次数。
- 采购进度：未发起采购、待确认采购、采购中、分批入库中、已完成入库、历史采购待核对。采购已完成后若公共库存被其他单消耗，允许显示“已完成入库 / 本单缺货”。
- 有效售后编号按店铺唯一；已删除售后单不再占用编号。删除后重建可复用 `CF原订单号`，旧单的 ID、商品、费用、物流和出库历史保留。
- 同一原订单若同时存在多张有效售后单，仍需不同编号，防止对单混淆。创建和删除使用同一店铺锁，数据库通过部分唯一索引兜底。
- 4PX 查询优先匹配未删除的同号售后单；已删除单仍保留旧运单，禁止将旧运单直接绑定到新单。
- 迁移 `c82fd850ab46` 将全局编号唯一约束改为有效单部分唯一索引；对有已删除前身、没有有效同号单、尚未绑定物流或回填、未出库的后缀单安全恢复原编号。其当前关联采购清单的显示编号同步修正，不改变数量、库存键、清点入库、分配或费用。
- 已经复用过编号后，不自动回退到旧的全局唯一约束；回退会破坏历史，需要人工核对。
