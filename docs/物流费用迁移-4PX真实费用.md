# 物流费用迁移：从「每日账单」到「4PX 按单真实费用」

## 一、先说现状（已查生产库）

| 数据 | 现状 |
|---|---|
| `order_costs` 订单物流费 | **0 条**（订单级物流费还没记过） |
| `expenses` 中 `shipping_cost` 每日账单 | **451 条，合计约 ¥475,028**，描述是日期（如 10.31），是当天汇总金额 |
| 每日账单与订单的关联 | 有 1,593 条分摊关联，但只是「按订单数量平均分摊」用于报表，不是每单真实费用 |
| `fourpx_freights` 4PX 真实费用 | 目前只同步了 3 单 |

所以现在的实际情况是：**你在费用管理里记的是每天的总账单，订单级物流费是空的**。  
这就是为什么你“不知道哪些订单记过费”——因为旧账单本来就没有订单级明细。

## 二、迁移目标

- 从某个**切换日**开始，每个已出库订单的物流费 = 4PX `ds.xms.order.getFreight` 返回的真实费用；
- 切换日之前的旧账单保留在「费用管理」里作为历史汇总，不再强行拆到每单；
- 订单利润/报表同一口径只取一次：有 4PX 真实费用的订单用真实费用，没有的才回退旧口径，绝不重复计算。

## 三、已上线的对账工具

入口：**费用管理 → 右上角「4PX 物流费对账」**（需先选具体店铺）。

功能：

1. **对账列表**：按日期范围列出已出库订单，显示
   - 4PX 单号、4PX 真实费用；
   - 已记物流费、来源（手填/账单/4PX）；
   - 差额、状态：`已记且一致 / 金额不一致 / 未记物流费 / 待同步4PX费用 / 无4PX单号 / 已记费用(非4PX)`；
2. **同步 4PX 费用**：对勾选或本页“待同步”的订单拉取真实费用（每批最多 50 单）；
3. **补记未记物流费**：只给「4PX 已有费用、订单还没记物流费」的订单写一条 **pending** 费用：
   - 来源标记为 `4px`，记录 4PX 单号与同步时间；
   - **不覆盖**手工/账单来源的金额；
   - **不自动确认、不扣账户余额**，仍需按原流程确认。

后端接口：

```text
GET  /api/order-costs/fourpx/reconcile?shop_id=1&date_from=2026-10-01&date_to=2026-11-06&status=cost_missing
POST /api/order-costs/fourpx/apply      {"shop_id":1,"order_ids":[...]}
```

## 四、建议的迁移步骤

### 第 1 步：定切换日
建议用 **2026-11-01** 或下个月 1 号（按你们结账周期）。

### 第 2 步：回填历史 4PX 费用（只同步，不补记）
在「4PX 物流费对账」里分批勾选/按页同步「待同步 4PX 费用」，直到状态变成「未记物流费 / 已记且一致」。
> 4PX 接口只返回已出库/出账订单；查不到的会一直是「待同步」，属于正常。

### 第 3 步：补记切换日之后的订单
对切换日之后的已出库订单，点「补记未记物流费」；系统只补空费用，不动旧数据。
确认费用后按原流程扣 4PX 账户余额（如果有用账户余额）。

### 第 4 步：旧账单处理
- 切换日前的每日账单**保留**在费用管理里，作为历史总成本；
- 切换日后**停止再导入** `shipping_cost` 每日账单（避免和 4PX 真实费用重复）；
- 报表口径：订单级利润用 `order_costs`，公司级费用汇总保留历史 `expenses`；两者不要混算同一段时间。

### 第 5 步：日常自动化（下一步可做）
每天定时任务：
1. 找出已出库但还没有 4PX 费用的订单；
2. 调 `ds.xms.order.getFreight` 写入 `fourpx_freights`；
3. 若订单没有物流费，自动写一条 `source=4px, status=pending` 的订单费用（不确认、不扣账户）；
4. 金额和已记费用不一致时只报警，不覆盖。

## 五、注意

- 4PX 费用是**出账口径**（含挂号费、运费等），可能和每日账单有几分钱差异；
- 旧账单按订单平均分摊，本来就不是真实单均费用，不建议拿来和 4PX 逐单对差额；
- 如果你们已手工确认过某些订单的物流费，工具不会改它，来源会保留为手填。

## 六、当前可立即做的事

1. 打开「费用管理 → 4PX 物流费对账」，选店铺、选日期；
2. 先点「同步 4PX 费用」把可查到的费用拉回来；
3. 看「未记物流费」数量，再决定是否「补记未记物流费」；
4. 确认切换日后，停止导入物流费每日账单即可。
